# Лендинги домов

Сайт с лендингами готовых домов: одна страница на дом, адрес постоянный — `домен/<код>/`.

| Ветка | Что | Кто пишет |
|---|---|---|
| `draft` | черновик → GitHub Pages: https://tvoydom-landings.github.io/site/<код>/ (с пометками, закрыт от поисковиков) | агент |
| `main` | опубликованный сайт → сервер лендингов кнопкой «Опубликовать» | через PR, после проверки |

## Путь правки

1. Агент меняет дом или шаблон в `draft` → черновик сам собирается на Pages.
2. Роман смотрит черновик с телефона и одобряет.
3. Агент открывает PR `draft → main`, GitHub сам назначает проверяющего (`.github/CODEOWNERS`).
4. Проверяющий смотрит изменения, при необходимости правит в `draft`, сливает (**Create a merge commit**).
5. Actions → «Опубликовать» → Run workflow → `main` уходит на сервер.
6. Боевая ссылка и QR со счётчиком — в таблицу «Лендинги и ссылки».

## Что где

```
build.py                    сборка: data + template → _site/  (python3 build.py [--draft])
template/                   шаблоны страницы: default.py — основная тема, samara.py — тема Samara, common.py
shared/                     общие стили и шрифты (default/, samara/), landing.js — калькулятор, фото, КН
  calc/mortgage.mjs         движок расчёта ипотеки        ← пишет агент, руками не править
data/
  common.json               общее для всех домов: регион, задаток, расходы по сделке, способы покупки, банки
  mortgage.json             цифры семейной ипотеки: ставки, лимиты, взнос, сроки   ← пишет агент
  catalog.json              все дома в продаже — лента «Другие дома»                ← пишет агент
  houses/<код>.json         дом: адрес, площади, цена, статус, фото                 ← пишет агент
photos/<код>/               фото дома (уже сжатые, без метаданных)                  ← пишет агент
tests/                      проверки: python3 -m unittest discover tests
deploy/                     тексты workflow и инструкция для сервера
```

**← пишет агент** — эти файлы агент выгружает из карточек объектов и из калькулятора Продажника.
Правка руками в них перезапишется при следующей выгрузке: цену, площади, фото и ставки меняем через
агента (Романа), а не здесь. Шаблон, стили, `common.json` и проверки — общие, правятся здесь.

Цена меняется в одной строке `data/houses/<код>.json` → `"price"`; ставки и лимиты ипотеки — в
`data/mortgage.json`, и пересчитываются сразу на всех страницах.

## Правила страницы (проверяет сборка)

- Тексты о доме — только из карточки объекта (через агента).
- Только свои файлы: внешних скриптов, шрифтов и стилей нет; пути относительные.
- Черновик — с полосой «Черновик», жёлтыми пометками и `noindex`; чистовая — без них.
- Хранилище открытое: здесь только файлы сайта. Документы, заметки, ключи и пароли сюда не попадают.

## Локально

```sh
python3 build.py --draft && python3 -m http.server -d _site 8088
```
